Foothold logo concepts

Five directions, each shown on light, as an app icon and with the wordmark. All marks use flat-topped hexes, the same shape as the game map, so the logo and the map read as one system.

1. Claimed hex

Recommended, and used in the startup animation.

A hex in your colour with an F drawn like a run line. It's the simplest read at icon size and it is literally a piece of ground you hold.
